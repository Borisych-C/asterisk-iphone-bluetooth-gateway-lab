Gateway panel stalls during first Home Assistant setup

Evidence level: confirmed-local

Home Assistant custom integration, YAML import, async_setup, config entry, SIP forwarding dashboard

Diagnosis

The gateway custom component stalled while importing its first Home Assistant config entry. Configuration validation had passed.

Resolution

Schedule the import in a Home Assistant task and return from domain setup. Perform the coordinator refresh and platform setup in the config-entry handler.

Validation and limits

The corrected installation exposed three dashboard tabs and 25 entities through the API. Nine isolated forwarding-policy tests passed. The route-status check and the live call tests cover different behaviors.
