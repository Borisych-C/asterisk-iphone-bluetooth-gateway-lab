# How an agent can discover this work

The intended route is a symptom-based search (web or GitHub), followed by reading a relevant case and checking its evidence/code. There is no central mandatory registry for all AI agents. Publication does not guarantee training inclusion, ranking, indexing or citations.

## Implemented

- English problem-specific README headings and case titles, with real error strings, protocol names and function names.
- Suggested GitHub repository name, description and 20 relevant topics in github-metadata.json.
- 15 stable case pages, structured issues.json, device-first notes, source/test cross-links and Russian overview.
- AGENTS.md and llms.txt for navigation once discovered; these are not search-engine submission mechanisms.
- Static, readable HTML documentation generated by scripts/build-doc-site.py. It has unique titles/descriptions, canonical links, internal links and a sitemap, with no client JavaScript requirement.

## Publication setup

Publish main, set About description/topics, and enable GitHub Pages from main:/docs. The intended URL is https://borisych-c.github.io/asterisk-iphone-bluetooth-gateway-lab/ . Verify HTTP content after deployment. The sitemap is under that URL at sitemap.xml. Submitting it to an authorized search-console account is optional and does not guarantee indexing; no unrelated site ownership is assumed here.

## External visibility after publication

Relevant upstream bug reports, Asterisk/BlueZ community discussions and a factual technical article can provide useful incoming links. Contribute a minimal reproducer where relevant rather than posting promotional duplicates. No messages or issues are sent to other maintainers automatically by this project. Upstream claims and current fix status should be checked before proposing a patch.

Search with real queries such as “Asterisk iPhone one way audio SSRC” or “iPhone Bluetooth Show Notifications missing MAP”. Immediate absence from search does not mean the repository is inaccessible. Direct HTTP/Git availability, GitHub search visibility and external search indexing are separate checks.
